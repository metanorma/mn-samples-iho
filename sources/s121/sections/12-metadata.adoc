== Metadata

The S-121 Product Specification makes use of <<IHO_S_100>> and <<ISO_19115_2003>>
metadata. The Metadata in this dataset complies with S-100 Part 4a. The metadata
for an entire data product dataset is defined in <<table-1>>, <<scls-1-6>> in
this document. Additional metadata may be defined to be associated with any
feature instance in a dataset.

NOTE: Currently metadata addressing the Product Specification is described in
<<scls-1-6>>, <<table-1>> in this document. There will need to be some restructuring
to include dataset metadata in this section and rewrite <<scls-1-6>> in a future
version of this Product Specification.
